# -demo
胡闹厨房学习demo
《胡闹厨房》游戏 Demo

项目类型： Unity 3D  Demo
开发工具： Unity、C#

项目描述：

参考《胡闹厨房》的核心玩法，使用 Unity 独立开发多人合作烹饪类游戏 Demo。玩家需要在限定时间内完成食材获取、加工、烹饪、装盘及订单提交等操作，通过多人协作完成游戏目标。

主要负责 / 实现内容：

使用 Unity + C# 搭建游戏核心玩法及整体游戏流程
实现玩家角色移动、转向及基础动画控制
实现玩家与场景物体、食材及厨具之间的交互系统
实现食材拾取、放置、切割、烹饪、装盘等基础操作
实现不同厨房设备的交互逻辑
实现订单生成、订单完成及得分系统
实现倒计时、分数、订单等游戏 UI
使用 Collider、Trigger、Rigidbody 实现游戏中的物理交互
使用 Prefab 管理玩家、食材、厨具等游戏对象
搭建游戏场景并处理场景中的碰撞及交互区域
使用 C# 对游戏状态、玩家状态及订单状态进行管理
对游戏中的交互逻辑进行调试和优化

项目亮点：

将复杂的烹饪流程拆分为多个可复用的交互模块
通过状态管理实现食材从“原材料 → 加工 → 烹饪 → 成品”的流程
使用模块化设计实现不同食材和厨具的交互
完成完整的“接单 → 制作 → 交付 → 计分”游戏循环
具备 Unity 3D 游戏玩法系统独立开发经验
